1. DAG + Wave Execution

How it works: Features modeled as directed acyclic graph in dag.json. Topological sort creates parallel execution waves with automatic dependency resolution. Cytoscape.js renders interactive visualization with zoom, pan, and node search.

In This Project Features organized into waves based on dependencies. Parallel execution in isolated git worktrees. Blast radius computed for impact analysis.
✓ Zero dependency conflicts. Automatic critical path identification. Parallel feature development.

2. 3-Layer Knowledge System

How it works: Three knowledge layers — Layer 1: Static knowledge files in knowledge/, Layer 2: Dynamic subagent learnings in subagent-learnings.json (patterns, decisions, conventions), Layer 3: Built-in RAPIDS framework capabilities and best practices.

In This Project Layer 1: Project brief and domain knowledge. Layer 2: Patterns and decisions learned during implementation. Layer 3: Core RAPIDS capabilities like DAG execution, checkpoints, NO MOCKS testing.
✓ Context accumulates across features. Learnings persist and compound. Knowledge compounds with each iteration.
🗄️ View Knowledge Base →
⚙️

4. Deterministic Orchestrator

How it works: Python state machine in orchestrator.py computes exact next action from state files (manifest.yaml, progress.json, waves.json). Implements finite state machine with strict transitions: run features → run QA → system checkpoint → user review → merge → next wave.

In This Project Every implement phase action determined by orchestrator. No workflow hallucinations or missed steps. Full audit trail in iteration-history.yaml.
✓ Zero workflow hallucinations. Predictable execution flow. Every step logged and auditable.

5. NO MOCKS Testing Philosophy

How it works: Pre-commit hooks scan test files and block mock frameworks (jest.mock, unittest.mock, sinon, pytest-mock). All tests must be functional — executing against real running systems. Docker containers provide isolated test environments.

In This Project Test suite runs against real services. Mock frameworks blocked at commit time. Production parity guaranteed. Runtime validation proves the app actually works.
✓ No mock/prod divergence. Real integration coverage. Fewer production surprises.
Coming Soon
🔄

6. Checkpoint & Feedback System

How it works: System checkpoints run after each wave: functional tests, runtime validation (Docker build + container execution), and regression suite. Failures captured with blast radius analysis. User review checkpoint presents results. Feedback items routed to root cause phase (spec → plan, logic → implement).

In This Project Checkpoint results stored in .rapids/implement/checkpoint-results/. Feedback captured in JSON with classification, severity, and blast radius. Rework cycles target root cause.
✓ Quality gates enforced. Failures auto-classified. Root cause fixes, not band-aids.

🚀 The RAPIDS Differentiator

RAPIDS transforms Claude Code from a helpful assistant into a reliable enterprise delivery engine. Six integrated phases, deterministic orchestration, automated quality gates, and end-to-end traceability ensure predictable, auditable, production-grade outcomes.

⚙️ Deterministic Orchestration

Python state machine computes exact next action from state files. Zero workflow hallucination. Every step logged and traceable.

✅ Automated Quality Gates

System checkpoints run after every wave: functional tests, runtime validation, regression suite. Failures auto-classified and routed to root cause phase.

🔗 End-to-End Traceability

Problem → Research → ADRs → Specs → Features → Code → Tests → Deployment. Full audit trail for compliance and governance.

🧪 NO MOCKS Testing

All tests run against real services. Mock frameworks blocked by pre-commit hooks. Production parity guaranteed.

🌊 Wave-Based Execution

DAG-driven parallel feature development. Worktree isolation prevents merge conflicts. Automated checkpoint gates between waves.

💬 Feedback-Driven Rework

System and user feedback captured with blast radius analysis. Automated rework cycles target root cause phase, not symptoms.
